# FlowBoard API

API REST para gestão de fluxo de trabalho com **Kanban** como núcleo funcional e **conceitos selecionados do SAFe** (Program Increment, iterações, iteração IP, Features priorizadas por WSJF e capacidade das equipes).

Projeto acadêmico da disciplina **Integração DevOps** (Engenharia de Software), com foco na aplicação prática de DevOps e DevSecOps: Git/GitHub Flow, testes automatizados, CI com GitHub Actions, imagem Docker publicada no GHCR, deploy e rollback por digest, segurança da cadeia de entrega e observabilidade.

> 🚧 Em desenvolvimento. A documentação completa será publicada ao longo das próximas versões.

**Stack:** C# / ASP.NET Core 10 · Entity Framework Core · PostgreSQL 17 · xUnit · Docker · GitHub Actions · GHCR
